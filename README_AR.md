## الملفات التي يتم استبدالها

1. `sections/Navbar.tsx`
   - تفعيل زر تحويل اللغة في الـNavbar.
   - مزامنة اللغة مع `localStorage` وCookie وحدث `masar:locale-change`.
   - تحسين المسافات على الموبايل حتى لا يسبب زر اللغة تزاحمًا.

2. `components/layout/RootClientShell.tsx`
   - إضافة طبقة الترجمة العامة `GlobalLocaleTranslator` بدون تغيير منطق الصلاحيات أو الـBuilder أو السحب الشهري.

## الملفات الجديدة التي يجب إضافتها

3. `components/i18n/LanguageSwitch.tsx`
   - زر اللغة الموحد.
   - يظهر داخل الـNavbar.
   - ويظهر عائمًا في Landing / Login / Register / Forgot Password / Reset Password / Email Confirmed لأن هذه الصفحات لا تحتوي Navbar.

4. `components/i18n/GlobalLocaleTranslator.tsx`
   - يطبق اللغة على الصفحات العامة وصفحات الطالب.
   - يضبط `lang` و`dir` تلقائيًا.
   - يترجم النصوص التي تظهر ديناميكيًا بعد التحميل أيضًا بواسطة `MutationObserver`.
   - يحول عناصر `dir="rtl"` إلى `ltr` أثناء الإنجليزية ثم يعيدها عند العودة للعربية.
   - لا يعمل داخل `/admin` حتى لا يتدخل في لوحة الإدارة.
   - لا يتدخل في صفحات الشهادات والتحقق لأنها تحتوي نظام لغة مستقل بالفعل.

5. `lib/i18n/ui-translations.ts`
   - قاموس النصوص الإنجليزية + القواعد الديناميكية للأرقام والحالات.
   - يشمل واجهات التسجيل والدخول، الشروط والخصوصية، الملف الشخصي، المسارات والكورسات، أزرار الاشتراك، Dashboard، المشاريع، الاستبيانات، الشهادات وMasar Passport.
   - يتضمن ترجمات بيانات المسارات ومحطات الكورسات الحالية الظاهرة من قاعدة البيانات.

## اختبار الموبايل المهم

راجعي على الأقل عروض 360px و390px و430px، مع التركيز على:

- Navbar + زر English/العربية.
- أزرار Login/Register.
- عناوين التابات في Course وDashboard.
- النصوص الطويلة في Terms/Privacy.
- بطاقات المشاريع والشهادات.

الحزمة تضيف قواعد عامة تمنع النص الإنجليزي من الخروج قدر الإمكان، وتحوّل `text-right` إلى محاذاة يسار عندما تكون الصفحة LTR.

## ملاحظة مهمة عن المحتوى الديناميكي

الحزمة تترجم **واجهة المنصة** والنصوص المعروفة الحالية، لكنها لا تستخدم ترجمة آلية للنصوص الحرة التي يكتبها المستخدم أو الإدارة حتى لا تغيّر محتواها أو تنتج ترجمة غير دقيقة. لذلك:

- تعليقات الطلاب وآراؤهم تبقى بلغتها الأصلية.
- أسماء/أوصاف مشاريع الطلاب تبقى كما كتبها الطالب.
- أي إعلان جديد أو محتوى حر جديد يكتبه الأدمن بالعربية فقط سيظهر بالعربية حتى تتم إضافة نسخة إنجليزية له أو إضافته إلى القاموس.

هذا مقصود لحماية المحتوى، وليس خطأ في زر اللغة.
